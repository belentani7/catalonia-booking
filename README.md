# Catalonia Booking System

Sistema de reservas hoteleras con wizard de reserva, mapa interactivo y estudio de mercado.

## Características

- **Booking Wizard** — 4 pasos: destino/fechas, huéspedes, código promo, resumen
- **Mapa Interactivo** — Leaflet.js con +25 destinos
- **Estudio de Mercado** — KPIs, tabla competitiva, FODA, tendencias
- **Filtros de Hoteles** — Urbano, Resort, Adults Only
- **Sistema de Ofertas** — Descuentos dinámicos y códigos promocionales
- **Rewards Program** — Sistema de puntos y beneficios
- **Chatbot** — Asistente virtual con FAQ
- **Dark Mode** — Toggle oscuro/claro
- **Responsive** — Mobile-first con breakpoints
- **Custom Cursor** — Cursor personalizado magnético
- **Preloader** — Pantalla de carga animada
- **Smooth Scroll** — Lenis smooth scroll

## Destinos

- España: Barcelona, Madrid, Málaga, Islas Baleares, Canarias
- Europa: Roma, Lisboa, Praga
- Caribe: Cancún, Punta Cana, Riviera Maya, Cuba

## Tech Stack

- HTML5, CSS3 (custom properties)
- JavaScript ES6+
- Leaflet.js (mapas)
- Swiper.js (carruseles)
- GSAP + ScrollTrigger (animaciones)
- Three.js (hero canvas)
- Lenis (smooth scroll)
- Google Fonts (Inter, Playfair Display)
- Font Awesome 6
